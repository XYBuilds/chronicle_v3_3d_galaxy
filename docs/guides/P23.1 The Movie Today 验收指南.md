# P23.1 The Movie Today 验收指南

> **历史资料，不可按此执行。** 本指南仅保留已退役的 Today 流程证据；`today.json`（历史 Today 文件，不可执行）、`today_url`（历史字段，不可执行）、`pick_movie_today.py`、Today fallback 和相关 `workflow_dispatch` 步骤均不可生成、上传、恢复或路由。当前电影 OG 入口以 [`docs/system/og-index-worker-contract.md`](../system/og-index-worker-contract.md) 为准；`/today`（退役路由，不可执行）、`/og/today.png` 和 `/share/today` 是 reserved-retired surface，必须继续返回 404。

本指南用于验收 **P23.1（today.json 数据生产 + 客户端加载与 fallback；历史 Today 流程，不可执行）**。
目标是把“是否通过”变成可执行、可复现、可回归的检查项。

---

## 1. 验收范围（本指南覆盖什么）

- `scripts/cron/pick_movie_today.py`：按 UTC 日期确定性选片，写 `today.json`（历史 Today 文件，不可执行）
- `scripts/cron/nightly_vote_refresh.py` / `scripts/cron/monthly_refit.py`：导出后自动生成 `today.json`（历史 Today 文件，不可执行）
- `scripts/cron/upload_galaxy_r2.py`：上传 `today.json`（历史 Today 文件，不可执行） 到 R2，并把 `today_url`（历史字段，不可执行） 写入 manifest
- `frontend/src/lib/galaxyAssetUrls.ts`：解析并解析 `today_url`（历史字段，不可执行）
- `frontend/src/data/loadToday.ts`：加载与校验 `today.json`（历史 Today 文件，不可执行），失败时 Top-1000 fallback
- `frontend/src/store/galaxyDataStore.ts`：暴露 `todayMovieId` / `todayPayload` / `todayUsedFallback`

---

## 2. 通过标准（Definition of Done）

以下 7 项全部通过，才算 P23.1 验收通过：

1. 可生成符合契约的 `today.json`（历史 Today 文件，不可执行）（字段完整，`movie_id` 在 `movies[]` 内）。
2. 同一 UTC 日期，多次生成结果一致（确定性）。  
3. 跨 UTC 日期，结果变化（非固定死值）。  
4. CI 导出链路后包含 `today.json`（历史 Today 文件，不可执行）（nightly/monthly）。
5. R2 manifest 出现 `today_url`（历史字段，不可执行）且可访问。
6. 客户端在正常场景使用 `today.json`（历史 Today 文件，不可执行），并给出有效 `todayMovieId`。
7. 客户端在 4 类失败场景触发 fallback 且应用可继续工作（不崩溃）。

---

### 6.2 fallback 场景（必须至少覆盖 3 项，建议全覆盖）

#### 场景 A：today.json 网络失败
- 临时让 `today_url`（历史字段，不可执行） 指向不存在地址，或让本地 `/data/today.json` 返回 404。
- 预期日志：`[Today] fetch failed` + `[Today] fallback random Top-1000`

#### 场景 B：today.json JSON 格式/shape 错误
- 把 `movie_id` 改成字符串或移除 `date`。
- 预期日志：`[Today] JSON shape invalid` + fallback

#### 场景 C：`movie_id` 不在 `movies[]`
- 将 `movie_id` 改为一个不存在的大 ID。
- 预期日志：`[Today] movie_id not in galaxy` + fallback

#### 场景 D：`date` 陈旧
- 将 `date` 改为距离当前 UTC 超过 1 天。
- 预期日志：`[Today] stale date vs browser UTC` + fallback

**通过标准（四场景通用）**
- 不崩溃、不进入错误页；
- `todayUsedFallback === true`；
- `todayMovieId` 仍有值（来自 Top-1000）。

## 7. 失败判定与快速定位

| 现象 | 判定 | 优先检查 |
|---|---|---|
| 没有 `today.json`（历史 Today 文件，不可执行） | 不通过 | `nightly_vote_refresh.py` / `monthly_refit.py` 是否在 export+validate 后调用 `write_today_json_after_galaxy_export` |
| manifest 无 `today_url`（历史字段，不可执行） | 不通过 | `upload_galaxy_r2.py` 是否检测到 `today.json`（历史 Today 文件，不可执行），是否进入上传分支 |
| 前端 `todayMovieId` 始终为空 | 不通过 | `resolveTodayMovieId` 是否抛错；`movies` 是否为空；控制台 warn 日志 |
| fallback 不触发或触发后报错 | 不通过 | `loadToday.ts` 的 shape 校验、`fallbackTodayMovieId`、Top-1000 切片 |
| 同日结果不一致 | 不通过 | `pick_movie_today.py` 是否使用 UTC 日期与稳定排序池 |

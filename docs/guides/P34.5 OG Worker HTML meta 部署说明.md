## 1. 行为 SSOT（注入后爬虫所见）

| 路由 | `og:title` | `og:image` | `og:url` |
|------|------------|------------|----------|
| `/movie/:id`（KV 命中） | `{片名} ({年}) — The Movie Cosmos` | `https://themoviecosmos.com/og/movie/{id}.png?v={G}-{M}` | 请求路径 + query（如 `?lang=zh`） |
| `/movie/:id`（KV miss / 非法 id） | `The Movie Cosmos` | `/og/brand.png?v=og-brand-og-v1` | 同上 |
| `/today`（KV 命中） | **历史 Today 行为：不可执行** | **历史 `/og/today.png`：不可执行** | 历史请求路径 + query |

- **`og:description`**：固定短句（非影片 overview）；与 HUD locale **无关**。
- **浏览器**：与爬虫同一 HTML；仍加载 SPA（`main.tsx`），深链行为不变（Phase 30）。
- **Shell 来源**：Worker `fetch(SITE_ORIGIN/index.html)`；勿与 `/movie/*` 路由形成环（`/index.html` 仍由 Pages 提供）。

## 2. 部署清单（按顺序）

### 步骤 0 — 确认 P34.4 已就绪

- `themoviecosmos.com/og/*` → Worker `themoviecosmos-og`
- `curl -sI "https://themoviecosmos.com/og/today.png"`（历史 Today 命令，不可执行）最终 200 或 302→200 PNG

### 步骤 1 — 部署含 HTML 逻辑的 Worker

```powershell
cd E:\projects\themoviecosmos-og-worker
git pull   # 含 34.5 合并后的 main
npm test
npm run deploy
```

### 步骤 2 — 绑定 HTML 路由（Dashboard 或 Token）

**Workers & Pages** → zone `themoviecosmos.com` → **Workers Routes**（须 **先于** Pages SPA 通配）：

| Route | Worker |
|-------|--------|
| `themoviecosmos.com/og/*` | `themoviecosmos-og` |
| `themoviecosmos.com/movie/*` | `themoviecosmos-og` |
| `themoviecosmos.com/today*` | `themoviecosmos-og`（仅保留退役路由 guard，必须返回 404；**不可**按 Today HTML meta 步骤执行） |

> 仅改 `_redirects` **不够**；深链 HTML 必须由 Worker 注入 meta。

**API Token 权限**（`wrangler.toml` 内 `[[routes]]` 同步时需要）：

- Account：**Workers Scripts → Edit**（部署脚本）
- Zone `themoviecosmos.com`：**Workers Routes → Edit**（或 **All zones** 读+写路由）

若 `npm run deploy` 报 `Authentication error` / `403` on `/zones/.../workers/routes`，脚本**仍可能已上传**，但路由未更新 → 必须在 Dashboard **手动添加上表三行**，或换 Token 后重新 `npm run deploy`。

### 步骤 3 — 生产冒烟（电影路径；Today 项不可执行）

> **历史 Today 命令：不可执行。** 下方 `/today` 检查仅保留历史证据；当前应验证 `/today` 与 `/og/today.png` 返回 404。

将 `550`、`301334` 换成你 KV 中存在的 `movie_id`（可与 `today.json`（历史 Today 文件，不可执行）的 `movie_id` 对齐；该 Today 对齐步骤不可执行）。

```powershell
# Movie 深链：og:url / og:image / 片名标题
curl -s "https://themoviecosmos.com/movie/550" | findstr /i "og:url og:image og:title"

# 历史 Today 命令：不可执行；当前 `/today` 必须返回 404。
curl -s "https://themoviecosmos.com/today" | findstr /i "og:url og:image og:title"

# 保留分享 query（lang 不进 PNG v，但应在 og:url）
curl -s "https://themoviecosmos.com/movie/550?lang=zh" | findstr /i "og:url"

# KV miss → 品牌图
curl -s "https://themoviecosmos.com/movie/999999999" | findstr /i "og:image"
```

**通过标准**：

| 检查 | 期望 |
|------|------|
| `og:url` | `/movie/{id}` 或 `/today`（历史路由，不可执行；旧结论）非 apex `/` |
| `og:image` | Worker `/og/...` URL，含 `?v=`；**非** `/data/og-today.png`（历史 Today 资源，不可执行） |
| `og:title` | 影片路径含片名 + 年份；today（历史 Today 内容，不可执行）含 `The Movie Today` |
| 响应 `content-type` | `text/html; charset=utf-8` |
| 页面仍可交互 | 浏览器打开 `/movie/{id}` 仍进入 focus + Drawer（Phase 30） |

可选：用 [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) / X Card Validator 对 **已绑路由后的 URL** 再抓一次（34.8 正式矩阵）。

## 3. 与 Pages `_redirects` 共存

> **历史 Today 路径说明：不可按旧步骤执行。** Pages 的旧 `/today` rewrite 只在 Worker retired-route guard 已绑定且先于 Pages 生效时不会复活 Today；当前契约要求 `/today` 继续返回 404。

主仓 `frontend/public/_redirects` 仍为：

```text
/movie/*  /index.html  200
# 历史 Today rewrite：不可执行；当前 `/today` 必须由退役 guard 返回 404。
/today    /index.html  200
```

生产上 **Worker 路由优先**；未绑 Worker 时仍回退到 Pages 静态 meta（34.2 基线缺陷）。绑好后无需改 `_redirects`。

`/og/*` 不得被 SPA rewrite（见 `spaRedirects.spec.ts` 负向断言）。

---

## 4. 回滚

> **历史 Today 回滚步骤：不可执行。** 不得为恢复旧 Today HTML 而解绑或重新启用 `/today`；当前退役 guard 应继续返回 404。

1. Dashboard 删除 `themoviecosmos.com/movie/*` 与 `themoviecosmos.com/today` 路由（可保留 `/og/*`）。
2. 站点回退为全站 `index.html` 静态 meta（`/movie/:id` 预览再次错位，直至 34.6）。
3. **保留** KV 与子仓代码；无需恢复 `render_og_today`。

## 5. 常见问题

**Q：绑了 `/movie/*` 后白屏？**  
A: 看 Worker Logs；常见为 `fetch index.html` 失败（`SITE_ORIGIN` 不可达）。确认 `wrangler.toml` `[vars] SITE_ORIGIN = "https://themoviecosmos.com"` 与 apex 一致。

**Q：curl 仍看到 `og-today.png`（历史 Today 资源，不可执行）？**
A: 路由未指向 Worker，或 deploy 仍是 34.4 之前 bundle。重复步骤 1–2。

**Q：`?lang=` 会改变 OG 图吗？**  
A: **不会**。`lang` 可出现在 `og:url`；PNG `v` 不含 `lang`（计划 SSOT）。

**Q：34.6 还要做什么？**  
A: 主仓 `index.html` 默认 meta、`ogTodayImageCacheBustPlugin`、分享链显式 `?lang=`；apex `/` 可改品牌 `/og/brand.png`。

# P34.7 TMDB 合规检查清单

> **Disposition:** supporting reference only (compliance checklist). Product/legal surface still follows NOTICE + TMDB terms; not a current topic rewrite.

对照 [TMDB API Terms of Use](https://www.themoviedb.org/documentation/api/terms-of-use) §3（Attribution）与 [Logos & Attribution](https://www.themoviedb.org/about/logos-attribution)。

## 站点（主仓）

| 检查项 | 期望 | 证据 |
| --- | --- | --- |
| TMDB Logo | 使用官方 short 标记，且弱于本站品牌 | `frontend/public/assets/tmdb-logo-short.svg`；`TmdbAttribution` |
| 强制声明（英文） | *This website uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.* | `index.html` 静态 footer；`locales/*/attribution.notice`；About → TMDB 区块 |
| About / Info | TMDB 专节含 Logo + 声明 + API 条款链接 | `InfoModal` + `info.sections` heading `TMDB` |
| 持久可见 | 左下角 HUD 署名（全阶段，含封面） | `App.tsx` → `TmdbAttribution` |
| NOTICE | 与 API Terms 措辞一致 | 根目录 `NOTICE` |
| 无免责套话 | 不写「个人项目 / 成功率」类表述 | 本 Phase 范围审查 |

## OG Worker（子仓）

| 检查项 | 期望 | 证据 |
| --- | --- | --- |
| 海报 fetch 白名单 | 仅 `https://image.tmdb.org/t/p/...` | `src/poster.ts` `normalizePosterUrl` |
| OG 图底栏（可选） | *Data from TMDB* | `TMDB_OG_ATTRIBUTION`；`render/card.ts`、`render/brand.ts` |
| 单测 | 非 TMDB host / http / 非 `/t/p/` 路径拒绝 | `test/poster.spec.ts` |

## 条款核对（人工）

- [ ] 数据用途：离线展示 + 社交预览；非 TMDB 官方产品表述已覆盖
- [ ] 未将 TMDB 用作图床（仅 Worker 按需拉取 w342 海报）
- [ ] 缓存：galaxy 导出与 KV 索引策略符合「不长期缓存 TMDB API 响应」意图（海报 PNG 为渲染产物，非 API JSON）
- [ ] 商用：若未来收费/广告，需单独评估 TMDB Commercial Agreement（当前非本 TODO 实施范围）

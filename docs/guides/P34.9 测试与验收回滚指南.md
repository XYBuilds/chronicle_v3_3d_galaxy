## 4. 回滚（统一口径）

按影响面选择；**默认保留 KV 数据**（无害）。

### 4.1 仅关动态 PNG（保留 HTML 注入）

1. Cloudflare Dashboard → **Workers Routes**：删除 `themoviecosmos.com/og/*`。
2. 社交平台短期仍可能缓存旧 URL；新分享需等缓存过期或用新 `v`。

详见 [P34.4 OG Worker PNG 部署说明](./P34.4%20OG%20Worker%20PNG%20%E9%83%A8%E7%BD%B2%E8%AF%B4%E6%98%8E.md) §5。

### 4.2 关 HTML meta 注入（恢复全站静态 head；Today 路由步骤不可执行）

> **历史 Today 回滚步骤：不可执行。** 不得为恢复旧 Today HTML 而重新启用 `/today`；当前退役 guard 应继续返回 404。

1. 删除路由 `themoviecosmos.com/movie/*`、`themoviecosmos.com/today`（可保留 `/og/*`）。
2. `/movie/:id` 爬虫将再次看到 apex 静态 meta（34.2 基线缺陷）。

详见 [P34.5 OG Worker HTML meta 部署说明](./P34.5%20OG%20Worker%20HTML%20meta%20%E9%83%A8%E7%BD%B2%E8%AF%B4%E6%98%8E.md) §4。

### 4.3 紧急恢复静态 `og-today.png`（历史 Today 流程，不可执行；非默认）

> **历史 Today 回滚步骤：不可执行。** 不得临时恢复 Today 生成、R2/Pages 发布或 `og-today` cache-bust；本节仅作历史记录。

1. 在 `nightly_vote_refresh.py` / `monthly_refit.py` **临时恢复** `render_og_today_after_galaxy_export`（或手动 `python scripts/cron/render_og_today.py`）。
2. 恢复 R2/Pages 对 `og-today.png` 的发布路径（见 [P34.3 OG Index KV 上线操作指南](./P34.3%20OG%20Index%20KV%20%E4%B8%8A%E7%BA%BF%E6%93%8D%E4%BD%9C%E6%8C%87%E5%8D%97.md) §11）。
3. 主仓 `index.html` / Vite cache-bust 改回 `og-today` URL（需另开 PR）。

### 4.4 完全停用 Worker（Today 路由步骤不可执行）

> **历史 Today 回滚步骤：不可执行。** 解绑 Worker 时仍不得让 Pages fallback 复活 `/today`；退役路由必须保持 404。

1. 解绑 `/og/*`、`/movie/*`、`/today` 全部路由。
2. （可选）停用 Worker 脚本 `themoviecosmos-og`。
3. KV `OG_INDEX` 可保留；恢复 Worker 后 `sync_og_index_kv --scope full` 即可。

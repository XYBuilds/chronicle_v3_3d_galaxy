**Wheel 双模式（Phase 17 · 与 Tech / Design Spec 对齐）**

| 输入 | 行为 |
|------|------|
| **滚轮（无 Space 武装；且无 Ctrl 交由浏览器缩放）** | 维持 **macro Z**：写 **`zCurrent`**（及 idle 下 `camera.z = zCurrent - zCamDistance`），见上表 **`zScrollSpeed`**。 |
| **按住 Space + 滚轮**（仅宏观 idle） | **Dolly-to-cursor**：写 **`zCamDistance`**（clamp **`[2,30]`**），同步 **XY**（`Raycaster` + **`z = zCurrent`** 平面）；**`zCurrent` / fov 不变**。 |
| **松开 Space**（本轮曾武装 dolly） | **`zCamDistance → 30`**；随后滚轮恢复左侧 macro 行为。 |
| **`Ctrl + 滚轮`** | 浏览器页面缩放；画布 **不**劫持、`preventDefault`。 |
| **focus 会话**（`selecting` / `selected` / `deselecting`） | **整段滚轮 noop**（含 **Space + wheel**），保证 Perlin 与 **`vote_count`** 映射不变（状态机 spec §3.4.6）。 |

**Phase 15 · Cover（首屏文案速查）**：**`STRINGS.cover`** 含 **`title` / `start` / `startAriaLabel`**（`locales/en.json` **`cover`**；**无** `subtitle` 键）。首屏**无** Spinner 行与副提示长句；**Start** 吸底。加载四阶段 + Cover 交互见 **Tech Spec §1.4.7**、**Design Spec §3.5**。

| **P11.4** 片元色           | OKLab **L,a,b**（**a=C·cos h,b=C·sin h**）→ 线性 RGB **clamp [0,1]** → **sRGB**                                  | `perlin.frag.glsl` `hueToOkSrgb`                        | 低 **L** 时防止出色域导致伽马 **NaN**（脏色）                                                                                                                                                               |
| **P11.4** 法线             | **`cross(dFdx(vWorldPos), dFdy(vWorldPos))`** 与 **`vGeomNormalWorld`** 按 **`uFlatShadingMix`** 混合            | `perlin.vert.glsl`、`perlin.frag.glsl`                  |                                                                                                                                                                                                             |

| **P11.5** 材质（当前）     | `transparent: false`、`depthWrite: true`、`alphaTest: 0.01`                                                      | `planet.ts`                                             | 不透明化收口，降低阶梯边缘透明伪影                                                                                                                                                                          |

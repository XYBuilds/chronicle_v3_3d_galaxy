# TMDB 电影宇宙 · 视觉参数总表（开发者速查）

> **适用范围（必读）**  
> 本表仅供**人类开发者**建立心智模型与扫参入口，便于对照源码。  
> **不作为** Cursor / Agent 的默认上下文、事实源（SSOT）或实现依据。  
> **功能与交互**以 **`docs/project_docs/TMDB 电影宇宙 Tech Spec.md`**、**`TMDB 电影宇宙 Design Spec.md`**、**`星球状态机 spec.md`** 及 **源代码** 为准。**性能与准入**（Chrome Performance 三线、P8.4 Story fps、里程碑入口/出口表）见 **`docs/benchmarks/Phase 8 基线 P8.0 性能与 P8.4 准入.md`**（归档 / 基线簿，**非**功能规格 SSOT）。自动化助手应优先读 Tech Spec / 状态机 spec / 类型定义；本表为开发者速查，**非** Agent SSOT。
> **数据流 / palette 生成 / `genre_hue` 导出**以 **`docs/project_docs/TMDB 电影宇宙 Data Pipeline.md`** 为 SSOT。

**扫描基线**：仓库当前前端实现（P8.4 双 `InstancedMesh` + WebGL2 断言；Phase **10**–**12** 同上版；**Phase 13** `transitionDriver`、`uSelectionMode=2` 邻域球、轨道相机、Timeline/`bridgeZ`、`FocusSizeReferenceRings` + **`FocusLReference`**、搜索 X 与 **`uFocusNonTargetActiveAlpha=0.08`** 等已落地；`scene.ts` Bloom **生产默认关**），日期 **2026-05-01**。下表与 `galaxyMeshes.ts` / `galaxyIdle*.glsl` / `galaxyActive*.glsl` / `planet.ts` / `perlin*.glsl` / `constellation.ts` / `selectionMask.ts` / `scene.ts` / `screenRadius.ts` / `focusNeighborMask.ts` 对读为准；行号易漂移，请以搜索为准。

| `uFocusedInstanceId`                                                           | 初值 `-1`                                                                                                                                                                             | `scene.ts` 挂载后                                                                                                  | `selected` 时等于焦点 `instanceId`；`selecting` / `deselecting` 常为 `-1`                                                                                                        |

| **P11.1** `uFocusTargetInstanceId`                                             | 初值 `-1`                                                                                                                                                                             | `scene.ts`                                                                                                         | `selecting` / `selected` / `deselecting` 为 `pendingSelectInstanceIndex`，用于飞入阶段在 `uFocusedInstanceId=-1` 时仍识别「目标」active                                          |
| **P11.1** `uFocusNonTargetActiveAlpha`                                         | **0.08**                                                                                                                                                                              | `galaxyMeshes.ts`（**Phase 13.6** 由 0.10 下调）；可调 `__galaxyColor.focusNonTargetActiveAlpha`（clamp `0.02…1`） | 非目标 active：`mix(1, 本值, uFocusCameraBlend)`；目标实例恒 **1**                                                                                                               |
| **P11.2** `uFocusDimChroma`                                                    | **0.7**                                                                                                                                                                               | `galaxyMeshes.ts`；可调 `__galaxyColor.focusDimChroma`（clamp `0…1.5`）                                            | **仅 idle vert**：非焦点且 focus 时 `C → C_base × 本值`（乘子）                                                                                                                  |
| **P11.2** `uFocusDimL`                                                         | **1**                                                                                                                                                                                 | 同上；`focusDimL`（clamp `0.05…1.5`）                                                                              | **仅 idle vert**：非焦点且 focus 时 `L → L_base × 本值`（乘子；**1** = 不压明度）                                                                                                |
| **P11.2** `uFocusDimMode`                                                      | **0**                                                                                                                                                                                 | 同上；`focusDimMode`（`0`/`1`）                                                                                    | **idle** 非焦点降饱和/明度路径开关；与 **P12** `uSelectionMode` **独立**（多选 mask 不由本 uniform 驱动）                                                                        |
| **P12.5** `uSelectionMask`                                                     | **R8** `DataTexture`，尺寸由 `computeSelectionMaskAtlasDimensions(movieCount, maxTextureSize)` 决定                                                                                   | `galaxyMeshes.ts` + `selectionMask.ts`                                                                             | 每实例 0/1 写入 atlas；`NearestFilter`；`flipY=false`                                                                                                                            |
| **P12.5** `uSelectionMode`                                                     | **`0`** = 时间轴条带 `inFocus`；**`1`** = **search** mask 覆盖 `inFocus`（人名/genre）；**`2`** = **focus 邻域球** mask 覆盖 `inFocus`（CPU：pivot+R 内 id；与 `1` 互斥，focus 优先） | `scene.ts` 每帧与 `searchMode` / focus 态同步                                                                      | `2` 时顶点着色器**不**用 `uZCurrent`/`uZVisWindow` 条带公式算 `inFocus`（与 `1` 同构，mask 来源不同）                                                                            |
| **P12.5** `uSelectionCount`                                                    | 运行时写入                                                                                                                                                                            | `selectionMask.ts` `setSelectionMask`                                                                              | 当前选中实例数（mask 为 1 的 texel 数）                                                                                                                                          |
| **P12.5** `uMovieCount`                                                        | `movies.length`                                                                                                                                                                       | `galaxyMeshes.ts`                                                                                                  | 与实例数一致；着色器内用于 atlas UV                                                                                                                                              |
| **P12.5** `uSelectionAtlasWidth` / `uSelectionAtlasHeight`                     | 与 atlas 纹理一致                                                                                                                                                                     | 同上                                                                                                               | GLSL `texture2D(uSelectionMask, vec2((mod(id,aw)+0.5)/aw, (floor(id/aw)+0.5)/ah))`                                                                                               |
| **P11.0 预留** `uFocusOcclusionRadius`                                         | **未接入运行时**                                                                                                                                                                      | 状态机 spec §3.4.4（占位）                                                                                         | 近相机遮挡剔除方案保留接口名；本阶段未实装                                                                                                                                       |

# **TMDB UMAP 电影数据可视化艺术项目**

**系统架构与自动化数据管线规划书**

## **1\. 项目概述**

本项目旨在将 TMDB 电影数据库（基于 Kaggle 每日更新源）转化为基于 UMAP 降维算法的动态视觉艺术作品。项目提取万级电影的特征，映射为三维空间坐标，并在前端以粒子/星系等形式渲染展示。随着现实世界电影库的更新，这幅“宇宙”也将随时间演变。

## **2\. 最终技术栈决策**

经过多维度评估（成本、性能、自动化程度、国内访问连通性），项目暂定采用以下“Serverless (无服务器) \+ 纯白嫖”架构：

| 模块 | 选用技术/平台 | 核心优势与定位 |
| :---- | :---- | :---- |
| **前端托管** | **Cloudflare Pages** | **无限带宽**。承载 WebGL/3D 渲染所需的大量静态资源，避免高并发流量导致账单爆炸。*(注：需配置自定义域名以确保国内访问畅通)* |
| **数据库 & API** | **Supabase** | **BaaS (后端即服务)**。底层基于 PostgreSQL。无需手写后端代码，直接为前端提供高速数据抓取 API，完全足以应对 59K 量级的坐标点存储。 |
| **自动化与计算** | **GitHub Actions** | **免费的云端调度器**。挂载 Python 环境，每天定时执行爬虫与增量降维计算脚本。 |
| **核心算法** | **Python (UMAP-learn, Pandas)** | 负责数据清洗、特征提取与非线性降维。 |

## **3\. 数据管线设计 (Data Pipeline)**

本项目的核心难点在于 UMAP 降维的“重计算成本”与“坐标漂移”。因此，数据流被拆分为**增量更新**与**全量重映射**两套管线：

### **阶段一：冷启动 (Cold Start) —— 当前状态**

1. **本地计算**：在本地 PC 上使用 1M 条 Kaggle 数据进行过滤，筛选出约 59,000 条高质量数据。  
2. **生成基准模型**：执行 UMAP().fit\_transform(features)，计算初始 (x, y) 坐标。  
3. **保存模型**：导出训练好的 UMAP 模型 umap\_baseline.pkl，将其推送到 GitHub 仓库。  
4. **数据上云**：将带有坐标和元数据的 59K 条 CSV 数据直接导入 Supabase 的 movies 库中。

### **阶段二：每日自动化增量流 (Daily Delta Stream)**

此过程完全由 GitHub Actions 托管，**无人值守**：

1. **定时唤醒**：GitHub Actions 在每日凌晨 (如 UTC 20:00) 触发运行。  
2. **同步状态**：Python 脚本通过 Supabase API 提取当前数据库中最新的 movie\_id 或 release\_date。  
3. **获取新源**：通过 Kaggle API (kaggle datasets download alanvourch/tmdb-movies-daily-updates) 下载最新数据集。  
4. **数据清洗与过滤**：  
   * 截取大于数据库最新 id 的增量数据。  
   * 应用业务筛选逻辑，提取最终符合上屏要求的 **新电影**。  
5. **增量降维计算**：  
   * 加载仓库中的 umap\_baseline.pkl。  
   * 执行 mapper.transform(new\_movie\_features) 获得新坐标。  
6. **写入数据库**：通过 Supabase API 将这批新记录 INSERT 到生产数据库。

### **阶段三：半年度全量重映射 (Bi-annual Remapping)**

随着时间的推移，仅通过 transform 添加的新点会导致整体分布流失其拓扑学上的全局准确性（数据漂移）。因此需定期执行“大洗牌”：

1. **导出全库**：在本地高性能电脑拉取 Supabase 中现存的所有数据特征。  
2. **重新拟合**：执行全量的 fit\_transform，生成全新的全局坐标。  
3. **艺术化更新**：  
   * 将新坐标更新至 Supabase。  
   * *(可选进阶)*：在前端实现坐标插值动画。当用户在更新周期打开网站时，能看见所有“星星”缓缓向新的空间位置移动，形成一次壮观的“宇宙膨胀/重组”艺术效果。  
4. **模型替换**：用最新的 .pkl 模型覆盖 GitHub 上的旧模型，供下一周期的每日增量使用。

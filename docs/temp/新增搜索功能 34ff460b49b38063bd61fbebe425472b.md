# 新增搜索功能

Tags: Design
Priority: High
Review: Review - 9.0

1. 搜索框居中放在顶端，可选搜电影名/搜人名/搜genre，可以用叉叉一键清除关键词
2. 需要满足的3条用户体验：
    1. 搜电影名（包括其他语言的original name）关键词搜索 → 点击下拉联想栏中的正确联想 → 跳转到对应的星球focus态
    2. 搜人名（cast, director, director_of_photography, writers, producers, music_composer）关键词搜索 → 点击下拉联想栏中的正确人物 → （禁用viswindow）所有该人物参与的电影星球都变成active，且按照时间顺序用细线链接（类似星座图），其他电影为idle态
    3. 搜genre → 点击下拉联想栏中的正确genre → （禁用viswindow）所有包含该genre的电影（无论是否是genre0）都变成active，其他电影为idle态
3. 联想栏
    1. 电影名联想
        1. 过滤 (Filter)
            1. 条件：搜索词（忽略大小写）被包含在 `title` 或 `original_title` 中。
            2. 仅做前缀匹配和包含匹配，**不需要**做模糊匹配（Fuzzy matching）或拼写纠错。
        2. 排序 (Sort)
            1. 第一维度（匹配类型）：前缀匹配（Starts with）的优先级 > 包含匹配（Contains）。
            2. 第二维度（加权热度）：当匹配类型相同时，计算得分 `Score = Math.log10(vote_count + 1) * vote_average`。按 Score **降序**排列。
            3. 注意：`release_date` 绝对不要参与排序逻辑。
        3. 格式化提取 (Format)
            1. 文本拼接格式为：`Title 原始标题 (YYYY) Genre0`。
            2. 注意去重：如果 `original_title` 和 `title` 相同或为空，则不要重复显示原始标题。
        4. 关键词高亮 (Highlight)
            1. 必须实现高亮：在最终渲染的文本中，用正则（忽略大小写）匹配用户输入的搜索词，并将其用带特定样式包裹。
    2. 人名联想（参考上文）
        1. 前缀匹配和包含匹配
            1. 同上，搜索词（忽略大小写）包含在cast, director, director_of_photography, writers, producers, music_composer中
        2. 排序 (Sort)
            1. 第一维度（匹配类型）：前缀匹配（Starts with）的优先级 > 包含匹配（Contains）。
            2. 第二维度（参与数量）：当匹配类型相同时，计算人物参与电影数量。按 数量 **降序**排列。
        3. 格式：全名
        4. 同样高亮
    3. genre联想
        1. 前缀匹配和包含匹配数据库内所有genre
4. 如果有需要对数据结构的升级，可以调整数据处理管线。
